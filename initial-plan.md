Hello! I'm building this project and here are the intial plans for it. I want it to be very similar to apache spark in that you can do pretty much everything in code (as in python or something). In particular, I want it to work work both with static data sources AND with data sources that are sort of "streamed" in.

But what is the goal of the overall project? The goal is to make something called TracePress, which uses heirarchical map reduce operations to search through peoples traces. I want it to use DSPy under the hood, and to have DSPy-like signatures for mapping from inputs to outputs. There is a similar project called lotus which has a similar interface, but the core issue here is I want to be able to specify some kind of operations that can operate on data which is streamed in in real time. For example, some operations may be triggered each time a new step happens in the trace. Another might be triggered when the trace itself has finished.
